# jabir.dev

Personal site and scientific notes, built with Next.js, React and trusted repository MDX. The visual identity draws on Dao Ho; the scientific publishing work draws on Distill's explanatory methods.

Agents: begin with [AGENTS.md](AGENTS.md) and the [scientific publishing handoff](docs/scientific-publishing/README.md). They document editorial decisions, actual APIs, module continuity, parallel ownership and validation limits.

Use `npm ci` in a clean checkout and `npm run dev` to start locally. The current course pilot is `/notes/es98a/week1`; `/dev/scientific-components` is development-only. See the [architecture guide](docs/scientific-publishing/architecture.md) for test commands and runtime details. Existing migration changes must be reviewed before broad staging or cleanup. Deployment requires approval.
