## Conceptual route

Fit a physical model → measure and reconstruct components → understand matrix transformations and inverse sensitivity → describe uncertainty probabilistically → compute expectations → move from vectors to functions → describe random functions → regularise reconstruction → condition distributions on data → quantify posterior stability and make predictions.

## Notation and assumption ledger

- Scalars are in K = R or C; the inner product conjugates its **first** argument and is linear in its second. `A*` is the conjugate transpose/adjoint. Real examples use transpose equivalently.
- Preserve the course convention `(a⊗b)x = ⟨a,x⟩b`, hence `a⊗b = ba*`. The first vector measures in the domain; the second reconstructs in the codomain. This differs from common tensor ordering.
- Use ψ for basis directions, α for coefficients locally; later α also denotes regularisation and must be reintroduced. Use θ for model parameters, ε for strain, σ for stress only in the Hooke example. Later σᵢ denotes singular values and σ² noise variance; state the switch.
- Distinguish input x, unknown parameter θ (later u), observed vector y (sometimes b), and predicted Aθ. Do not silently identify a random variable with its realised value.
- ONB gives exact finite reconstruction/Parseval; infinite expansions need completeness and norm convergence. L² elements are equivalence classes a.e.; evaluations require RKHS regularity. Fourier/Sobolev statements here require a periodic interpretation.
- Hermitian eigenvalues may be negative; SPSD allows zeros; SPD excludes them. Covariance need only be SPSD; a full-dimensional Gaussian density needs SPD. Infinite-dimensional strict positivity alone does not imply a bounded inverse.
- Least-squares uniqueness requires injectivity/full column rank. Compact infinite-rank pseudoinverses need a domain/Picard condition. Projection onto a subspace requires closedness in Hilbert spaces.
- IID finite-variance sampling supports the MC RMSE formula; integrability suffices for the stated iid LLN. Invariance alone is not ergodicity or mixing. GP finite-dimensional distributions need valid PSD kernels; almost-sure path regularity needs separate hypotheses.
