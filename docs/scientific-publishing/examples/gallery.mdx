## Direct primitive authoring

<LinkedEquation>

For a unit direction u, <LinkedTerm term="projection">P² = P</LinkedTerm>.

<LinkedMark term="projection">Projecting a vector already on the line leaves it unchanged.</LinkedMark>

</LinkedEquation>

    question="A unit vector u defines Px = ⟨u,x⟩u. What happens if we project Px again?"

    ]}
