## Definitions and assumptions that now persist

- Inner product conjugates its first argument. `(a⊗b)x = <a,x>b`; input direction first, output direction second. Complex Hilbert–Schmidt identification uses conjugate domain tensor space.
- Finite parameters use theta/x, function unknowns use u, observations y/b. Singular values sigma_n differ from the noise variance sigma² in GP regression; regularisation alpha differs from the MH acceptance probability alpha(x,x'). Each is locally defined.
- Hilbert expansions converge in norm; L2 identifies functions a.e. Periodic Fourier Sobolev spaces have strict embedding thresholds; negative spaces require distributions/completion. Operator scale induced by inverse Laplacian has twice the usual Sobolev order.
- Covariances may be semidefinite. Gaussian ambient densities need SPD; infinite-dimensional covariances need trace class. Strict positivity does not imply uniform coercivity.
- MC LLN assumes iid integrability; RMSE assumes finite variance. MCMC stationarity is not ergodicity. Gap estimate assumes stationarity and an absolute operator gap on mean-zero L2.
- Point evaluation is not an L2 functional. Mercer conclusions use a compact domain and finite full-support measure; real symmetric SPSD continuous kernel. General L2 kernel diagonals are not operator invariants.
- Pseudoinverse formulas have a Picard domain; exact recovery assumes the unknown perpendicular to the null space. Tikhonov convergence needs alpha→0 and delta/sqrt(alpha)→0; source conditions supply rates rather than being necessary for pointwise convergence.
- Bayes likelihood must be jointly measurable, with positive finite evidence at data values used. Linear observations on Hilbert space are bounded. GP noiseless interpolation requires invertible Gram matrix. Posterior latent variance differs from future noisy-observation variance.
