# ES98D animation reference

These are module-owned React components. They are not shared MDX exports. No change to the global compiler, registry, article CSS or gallery was needed.

## Components and placement

`ES98DAnimation({ kind, overview? })` in `src/components/scientific/modules/es98d/animations.tsx` renders a registered shared Figure with a module client island. `kind` is one of the eighteen entries in `animation-catalog.ts`; The optional legacy `overview` flag adds an ID suffix; it is currently unused because the contents page is static. Each kind occurs at most once on a page. Do not place a duplicate instance with the same kind/overview combination on one page without adding an explicit ID strategy.

`animatedES98DArticle(topic, source)` is server composition, not a new MDX compiler. It locates two explicit existing h2 anchors from `motionPlacements`, splits only between complete sections, compiles each section with the unchanged `scientificMDX`, and interleaves directly imported React figures. An absent anchor is an error. All existing chapter text and static figure markup are preserved. Inserting a new animation does not make arbitrary JSX names available in MDX. The route owns its component keys so changing chapter/kind resets that experiment.

`AnimationScene` renders two responsive SVG panels, each preceded in DOM order by its own panel title. The layout stacks panels on narrow screens. It uses existing article accent colours with independent labels, strokes, formulas, metrics and detailed captions. SVG coordinates are rounded for consistent browser/server HTML; numerical model values retain their precision. Phase-space orbit diagrams preserve equal axis scales. Metropolis proposals outside the displayed energy range are explicitly marked and keep their true energy difference in the readout.

## Playback and accessibility

Initial state is paused at position 18%, providing a useful mathematical still. Play runs an eighteen-second sequence at no more than thirty React updates per second. At the endpoint it stops. Restart returns to position zero and preserves the selected parameter. Step advances one of 120 model intervals. Scrubbing pauses playback. Changing a parameter pauses, returns to zero and rebuilds the same-seed model for comparison. There is no autoplay and no animation dependency for reading the derivation.

The player pauses when its section leaves the viewport or the document becomes hidden. With reduced motion enabled, timed playback is disabled; stepping, scrubbing and parameters still work. Play/pause, Step and Restart are native buttons. Both ranges have explicit labels and at least 44px input height. One polite status region announces playback state; continuously changing numerical text is deliberately not an aria-live announcement. Each SVG's accessible name includes its panel title and current mathematical summary. The same graphic, metrics and a noscript explanation are server-rendered when JavaScript is unavailable. A real screen-reader audit has not been performed.

## Numerical model boundary

`animation-math.ts` has no React or browser dependency. `buildMotion(kind, parameter)` returns deterministic snapshots, curves and the model identity. Fixed-seed random innovations are generated by a 32-bit LCG and Box–Muller transform. These are reproducible teaching examples, not production random-number infrastructure. Parameter bounds come from the catalog; the internal builder assumes those reviewed bounds.

`motionFrame` interpolates presentation positions between computed snapshots where appropriate. Analytic spin/force/phase/free-energy relations are reevaluated at the displayed coordinate; phase orbit energies are conserved even between snapshots. Discrete samplers, cluster constructions, finite-sample statistics, Verlet updates and event decisions are stepped without inventing fractional decisions. Sampled OU positions are joined for display, not claimed as an exact Brownian bridge. Plotted histories still consist of computed observations.

The exact event-threshold sequence is explanatory and deterministic, not a claimed random equilibrium trajectory. The SPH compression and force scenes prescribe positions and do not integrate a fluid. The free-energy surface is a mathematically defined two-dimensional valley with an analytically integrated transverse Gaussian; the finite drawing window does not truncate that integral. Umbrella curves use exact fixed-grid reweighting and do not establish finite-trajectory overlap. Every relevant limitation is visible in the figure itself.

## Working examples and validation

All eighteen live examples are embedded across the nine ES98D chapters. The course index contains no animations, following the user's subsequent clarification. The shared executable gallery is unchanged because no shared API changed. `animation-plan.md` records the complete chapter/purpose mapping.

Run module checks explicitly:

```sh
npx tsx --test tests/scientific/es98d/math.test.ts tests/scientific/es98d/content.test.ts tests/scientific/es98d/animations.test.ts
ES98D_BASE_URL=http://localhost:3014 ES98D_ARTIFACTS=artifacts/es98d/animations-production npx tsx tests/browser/es98d/animations.ts
```

The browser script accepts an existing URL and never starts or kills a server. It checks both animations on every chapter and verifies that the index has none, including playback, controls, pointer/keyboard/touch, responsive bounds, labels, hydration, both themes, reduced motion and no-JavaScript content. It writes a JSON report and per-experiment screenshots. The existing `inspect.ts` now targets the original article-level static figure, so adding nested animated figures does not invalidate its original checks. Test discovery in the root numerical command remains a separate shared integration task.
