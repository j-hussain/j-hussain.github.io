## Interaction contract

Two PredictReveal instances, in Ch4 and Ch6. Initial state: no selection, reveal disabled. Choices are mutually exclusive; reveal explains either response without scoring. Reset clears choice and result. Shared native radio/buttons support keyboard and touch. The essential explanation is in noscript and surrounding prose. There is no animation or hidden proof dependency.

## Reproducible diagram contract

Nine figures / eighteen panels use native SVG within the registered Figure component and existing two-panel story classes. No new component registration, API or global CSS is required. Native SVG is deliberately generated into the MDX, with all numerical calculations outside React. `math.ts` supplies computations, `figures.ts` builds teaching diagrams, and `generate-figures.ts` regenerates or checks only the nine owned chapters. The content test compares normalised generated figure markup, and numeric tests check independent analytic cases and invariants. No screenshot is an empirical dataset.
