## Authoring API and working examples

Use `<PX457Animation scene="pipeline" />` through `px457MDX`, imported from the module's `article.tsx`. The sole prop is a catalogue scene ID. The scene owns the fixed figure ID `px457-animation-<scene>` and must appear at most once on a page. Unknown IDs fail explicitly. The [working gallery](animations-gallery.mdx) compiles every scene through the actual adapter; the same components appear in the fifteen chapter routes. The contents is intentionally animation-free and uses the shared compiler directly; only chapter routes need the module animation registration.

- `animation-catalog.ts`: title, question, two named comparisons, assumptions, endpoint explanation, milestone count and reader-time duration. Comparison zero is the deterministic server-rendered choice.
- `animation-math.ts`: pure floating-point examples, instruction start times, cache traces, schedules, reductions, diffusion states, broadcast edges, rank maps, memory segment counts and AD trace values.
- `animation-frames.ts`: pure SVG geometry and explanations from `(scene, progress ∈ [0,1], comparison ∈ {0,1})`. Circle/rectangle ports prevent connection strokes crossing node text. Progress interpolation visualises transitions; it does not redefine algorithmic states or imply fractional process counts.
- `animations.tsx`: the module's client island and one reader-controlled clock. Uses the existing Figure component. Play starts a twelve-second explanatory sequence; Pause freezes it; Next step advances one scene milestone; Restart returns to the start while retaining the selected comparison; changing comparison stops and resets time. The labelled native slider supports keyboard and direct manipulation. Playback stops at the end, when the section leaves view, or on a hidden-document event. Reduced motion disables continuous playback while retaining stepping and scrubbing. There is no autoplay or automatic loop.
- `article.tsx`: preserves the shared compiler and map, with explicit module-local component registration. No external MDX is accepted and no trust policy or compiler configuration changes.

The shared owner can replace the small cloning adapter with a reviewed optional component-map argument on `scientificMDX`, merge rather than replace the registered map, and exercise this gallery plus existing consumers. Proposed signature: `scientificMDX(source, extraComponents = {})`. That change needs shared docs/gallery compatibility checks and is deliberately not implemented in this module assignment. The inspected installed `next-mdx-remote/dist/rsc.js` is the authoritative current contract; [React's cloneElement reference](https://react.dev/reference/react/cloneElement) explains the prop merge. The clock follows [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) and respects [prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion).

## Mathematical and visual review decisions

The warp view considers all eight illustrative lane requests together, avoiding a misleading serial-load trace. Cache hits return from resident storage; misses visibly replace the mapped tag. Rank reordering keeps the Cartesian slots still and follows one physical process identity, avoiding unreadable colliding rank labels. The scaling view uses side length 24, divisible by process-grid sides 1, 2, 3 and 4, and aligns its morphing grid lines with the highlighted subdomain. Graph connections meet node borders so primal/partial-sum labels remain readable. No unverified hardware rate, new convergence theorem or machine-learning lecture is inferred from these teaching examples.

Forward and reverse AD use the source's function at `(2,0.7)`. The animation shows actual local derivatives and accumulated contributions, rather than merely reversing the direction of decorative arrows. Recursive doubling displays exact partial sums; the chunked ring intentionally displays phase and chunk size, not invented full-buffer partial sums. Read the caption before interpreting each view as a numerical algorithm trace.
