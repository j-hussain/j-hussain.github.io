## Definitions and notation ledger

- Chapter 1: FLOP = arithmetic operation; FLOP/s = rate; binary32 precision 24 significant binary digits (including hidden bit), unit roundoff `2^-24` for round-to-nearest. Integer arithmetic exact only within range. Energy `E = W T` for constant power `W`.
- Chapter 2: latency `L` versus initiation interval `I`; ideal pipeline `L+(n-1)I`; floating-point transformations need an explicit error tolerance. C arrays zero-based throughout.
- Chapter 3: toy word size 8 bytes, line length 16 words, 4 direct-mapped slots; `block=floor(wordAddress/16)`, `slot=block mod 4`. This is a pedagogical model, not a real-CPU specification. Row-major C, column-major Fortran.
- Chapters 4–7: `P` team size, `N` iteration count, thread IDs `[0,P)`. Private scalar storage differs from pointed-to allocation. `lastprivate` follows sequential logical iteration order. A reduction changes floating-point association.
- Chapters 8–12: `P` communicator size, `r` local rank `[0,P)`; ranks never globally meaningful without communicator. `n` elements per message, datatype determines representation; bytes denoted `m`. Requests delimit buffer lifetimes. `alpha` latency and `beta` seconds/byte belong to an illustrative model.
- Chapter 13 retains source symbols: `T(N,P)`, serial work `sigma(N)`, parallel work `pi(N)`, elapsed overhead `kappa(N,P) >= 0`, speedup `psi`, efficiency `epsilon`, algorithmic fraction `F`, measured Karp–Flatt `F_KF`. All measured comparisons specify baseline and fixed work. Weak scaling fixes work per processor, which need not mean `N/P` for superlinear algorithms.
- Chapter 14: block width `B`, blocks `G`, thread index `t=Bb+q`, grid stride `BG`. `N=0` skips launch. A CUDA thread is not a CPU core.
- Chapter 15: `f:R^n -> R^m`, `J` is `m by n`; forward tangent `Jv`, reverse adjoint `J^T w`. Toy function requires `x1>0`. The bar notation is a derivative sensitivity, not complex conjugation.

## Assumptions and recurring representations

C examples are teaching kernels unless labelled complete programs. Bounds, nonaliasing, nonzero divisors and input lifetime are stated locally. MPI examples use the World model and intracommunicators; MPI extensions (sessions, one-sided and nonblocking collectives) remain out of scope. OpenMP examples target the common C subset supported by the teaching compiler; optional newer constructs are labelled. CUDA targets NVIDIA devices and a chosen toolchain; no actual device timing is inferred.

Fixed SVGs carry labels and stroke distinctions as well as existing theme colours. Time grows rightward in execution timelines; cells represent logical indices in ownership diagrams, not physical bytes unless explicitly labelled. All numeric plots are analytic teaching models, never empirical benchmarks. Static proofs and reference figures remain; the user’s subsequent assignment adds two reader-controlled process animations per chapter, documented in `animations.md`.
